      Reading the numbers

      • KSI = people killed + people with incapacitating ("serious") injuries in a crash.
      • A chart for a filtered field keeps showing every value (counted under all the other filters), so you can add or swap values. Selected values are highlighted.
      • Hot spots are ~80 m grid cells. The label is the block of one crash in that cell.
      • "Neighborhood" uses the city's 77 community areas, the boundary file this project was given.
      • The filter state is kept in the page address, so you can share a filtered view by copying the URL.
